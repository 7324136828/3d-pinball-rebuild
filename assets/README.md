# Runtime assets

`table.json` is the standalone runtime copy of the readable Space Cadet table
from `original-project/public/assets/table.json`. The Python backend reads this
file and serves it through `/api/table` in development and production.

The table data and text retain their original ownership; the engine's MIT
license does not relicense them. See [third-party notices](../THIRD_PARTY_NOTICES.md)
and [source provenance](../frontend/src/pinball/PROVENANCE.md).
