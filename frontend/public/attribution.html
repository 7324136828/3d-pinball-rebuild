Modern 3D Pinball: attribution and licenses

Modern 3D Pinball adapts the gameplay, physics, missions, and procedural renderer supplied in original-project. That original implementation is preserved in the repository.

Reconstructed Space Cadet engine

The JavaScript gameplay modules translate the MIT-licensed reconstructed engine by alula/SpaceCadetPinball (commit 0bc12d3ca97a30a61e1e325cfde1eeec379bb9b9), based on k4zmu2a/SpaceCadetPinball. Copyright (c) 2020–2021 Andrey Muzychenko.

Table data and presentation

The readable table geometry was exported from the supplied Windows Space Cadet table, PINBALL.DAT (SHA-256 42defd5d2a339a3953fe643716aff4e35b2cea7a3e54505c82d1e78d5325bc04). The table data and original text retain their original ownership; the engine's MIT license does not relicense those materials.

The modern 3D cabinet uses procedural artwork and geometry. Audio is synthesized with Web Audio; original recordings and bitmap pixel data are not distributed in the application.
